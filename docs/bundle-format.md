# レビューファイル(`.diffnote`)の形式

`.diffnote` は zip ファイルで、どの zip ツールでも開けます。保存のたびに、ファイル全体が書き直されます。diffnote の知らない項目は、そのまま引き継がれます。

```
review.jsonl          レビューの記録(1 行に 1 つの出来事)
settings.json         レビューの設定
reactions.json        リアクション
attachments.json      添付の元のファイル名
commits.json          コミットの情報(git のレビュー)
diffs/<digest>.diff   各リビジョンの差分
blobs/<sha256>        ファイルの版(内容のダイジェストが名前)
images/<digest>       添付した画像
attachments/<digest>  添付したファイル
```

## 記録(`review.jsonl`)

1 行に 1 つの出来事を JSON で書いた、追記していく記録です。ID は ULID です。

- `meta`: レビューを作ったこと。
- `revision`: リビジョン。比べたもの(`git` なら base と head のコミット ID、ディレクトリならベースのスナップショット)、差分のダイジェスト、触れたファイルの版、保存したツリー、スナップショットの範囲、base から head までのコミット ID の列(古い順)。
- `pin`: 記録済みのリビジョンに、あとから必要になったファイルの版を足す(差分が触れていないファイルに、コメントが付いたとき)。
- `comment`: コメント。スレッドの最初のコメントは場所(下の「位置」)を持ち、返信は `parent` にスレッドの ID を持ちます。
- `resolve` / `reopen`: 解決と再開。
- `reanchor`: スレッドの位置の付け替え。今の diffnote は書きませんが、以前の版で作られたものは読んで、位置に反映します。

コメントの編集と削除は、この記録そのものを書き換えます(履歴は残りません)。以前の版が記録した `title` / `ignore_whitespace` の出来事は、最後の値が設定として読み込まれ、次の保存から `settings.json` に書かれます。

## 位置

コメントの場所は、「あるファイルの版(内容のダイジェスト)の、この行範囲」です。本文の引用や前後の行は保存しません。

- `Global`: レビュー全体
- `File`: ファイル全体(変更前・変更後の版)
- `Span`: 変更前と変更後のそれぞれの行範囲。長さ 0 の範囲は、その行の手前の位置(追加された行に対する変更前の側など)

別のリビジョンで表示するときは、記録された版どうしの行差分をたどって、範囲を移します。変わっていない行はずれるだけ、置き換えは同じ行数なら 1 行ずつ、違えばまとめて、消えた行は消えた位置になります。似た行を探して推測することはしません。参照するファイルの版は、必ずレビューファイルの中にあります。

## スナップショットの範囲

最初のリビジョンの範囲が、そのレビューの範囲です。レビューを作るときに決まり、変えられません。

- `changed`(git のレビューの既定): 差分が触れたファイルの両側と、コメントが参照するファイル。ほかは git が持っています。
- `full`: それに加えて head のツリー全体。ディレクトリのレビューは、いつもこちらです(比べる相手が、保存したスナップショットしかないため)。

`full` で保存する量が 30 MB を超えるときは、確認(git)か警告(ディレクトリ)が出ます。

## 状態のファイル

次のファイルは、履歴を持たない「今の状態」です。中身がないときは、ファイル自体が作られません。

- `settings.json`: `title`(タイトル)、`ignore_whitespace`(「空白の違いを無視」の既定)、`attachment_limit`(添付 1 つの上限。既定 5 MB、1 KB から 100 MB)。
- `reactions.json`: コメントごとの、絵文字と、付けた人の名前。コメントを削除すると、そのリアクションも消えます。
- `attachments.json`: 添付のダイジェストごとの、元のファイル名。添付は内容で 1 つにまとめられるので、同じ内容が別の名前で添付されたときは、先に付いた名前が残ります。クリップボードからの貼り付け(ブラウザが一律に `image.png` と名付けるもの)は、名前を記録しません。
- `commits.json`: コミット ID ごとの、作者・日時・件名・本文・変更したファイル。どのリビジョンがいくつ同じコミットを参照しても、中身は 1 回だけ入ります。エクスポートした HTML にはリポジトリがないためと、あとで履歴が書き換えられても、記録した時点のものが残るように、保存しておきます。トレーラー(`Co-Authored-By:` など)も、そのまま残します。

保存のたびに、どのリビジョンにも含まれなくなったコミットと、レビューファイルから消えた添付の名前は取り除かれます。どのコメントからも使われなくなった添付そのものは、`serve` の「終了」のとき(と、画面の「添付」で消したとき)に取り除かれます。
